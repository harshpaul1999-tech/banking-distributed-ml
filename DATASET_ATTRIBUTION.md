# Dataset attribution

The supplied 4,521-row, 17-column file matches the sample variant of the Bank Marketing dataset:

S. Moro, P. Rita, and P. Cortez. “Bank Marketing.” UCI Machine Learning Repository. DOI: [10.24432/C5K306](https://doi.org/10.24432/C5K306).

The UCI record identifies the bank.csv file as a random 10% sample of the older 17-input version and lists the dataset under the Creative Commons Attribution 4.0 International (CC BY 4.0) license. Please retain this attribution when sharing adapted copies.
